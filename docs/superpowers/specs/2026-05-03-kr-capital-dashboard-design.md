# KR_CAPITAL 월간 운용 보고서 대시보드 설계

## 개요

KR_CAPITAL 자산 운용 대시보드. 단일 HTML 파일로 구성.
- **운용자(본인)**: 매매 기록, 자산 추적, 월간 운용 내용 입력
- **투자자(형)**: "보고서 출력" 버튼으로 깔끔한 월간 보고서 PDF 생성

## 핵심 원칙

- 30분 이내로 월간 보고서 작성 가능
- 직관적이고 간결 (과도한 전문성 불필요)
- 서버 없이 단일 HTML 파일로 완결
- 데이터는 localStorage + JSON 백업으로 관리

## 화면 구성

### 1. 대시보드 모드 (본인용)

#### 1-1. 상단 헤더
- "KR_CAPITAL" 로고/제목
- 월 선택 드롭다운 (2025년 4월, 5월...)
- "보고서 출력" / "JSON 백업" / "JSON 복원" 버튼

#### 1-2. 자산 요약 카드
- 이번 달 총 자산 금액
- 전월 대비 변동 (금액 + %)
- 출자/회수 내역 요약

#### 1-3. 자산 추이 그래프
- 일별 총 자산 라인 차트 (SVG 기반)
- 출자/회수 이벤트 마커 (점 + 사유 툴팁)
- X축: 날짜, Y축: 자산 금액

#### 1-4. 자산 배분 차트
- 한국주식 / 미국주식 / 현금 비중
- 도넛 차트 (SVG/CSS)

#### 1-5. 포트폴리오 테이블
- 종목명, 시장(KR/US), 수량, 평균매수단가, 현재가, 평가금액, 수익률
- 투자포인트 (한 줄 텍스트)
- 리스크 (한 줄 텍스트)
- 종목 추가/삭제 버튼

#### 1-6. 매매 기록
- 날짜, 종목, 매수/매도, 수량, 단가 입력
- 매매 내역 테이블 (이번 달)

#### 1-7. 출자/회수 기록
- 날짜, 금액(+출자/-회수), 사유 입력
- 내역 테이블

#### 1-8. 월간 텍스트 입력 영역
- 이번 달 운용 내역 (textarea)
- 반성 & 잘한 점 (textarea)
- 다음 달 계획 (textarea)

### 2. 보고서 모드 (형 전달용)

"보고서 출력" 클릭 시 인쇄 최적화 레이아웃으로 전환:

- KR_CAPITAL 헤더 + 보고서 기간
- 자산 요약 (총 자산, 변동, 출자/회수)
- 자산 추이 그래프
- 자산 배분 차트
- 포트폴리오 현황 테이블 (투자포인트, 리스크 포함)
- 이번 달 주요 매매 내역
- 운용 내역 / 반성 & 잘한 점 / 다음 달 계획
- Ctrl+P → PDF 저장

## 기술 스택

- HTML + CSS + vanilla JS (단일 파일, 외부 의존성 없음)
- 차트: SVG 직접 그리기
- 저장: localStorage
- 백업: JSON 파일 다운로드/업로드
